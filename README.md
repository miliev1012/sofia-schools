# Училища за първи клас — София

**Онлайн:** https://miliev1012.github.io/sofia-schools/

Или локално: отвори `index.html` с двоен клик (трябва интернет за картата).

Всяко `git push` към `main` публикува страницата наново (GitHub Actions → Pages).

## Структура
- `index.html` — страницата и табовете
- `css/style.css` — визия
- `js/app.js` — картата, списъкът, таблицата, сравнението, въпросите, копието
- `data/schools.js` — данните за училищата (адреси, телефони, район), колоните за сравнение (`FIELDS`) и общите въпроси (`QUESTIONS`)

Бележките, оценките и отговорите се пазят в браузъра. С „Запази копие“ се изтегля
JSON файл, който може да се зареди на друг компютър или телефон със „Зареди копие“.
